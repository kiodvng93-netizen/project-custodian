# PROJECT CUSTODIAN — MASTER STATE & HANDOVER (v4.0)
**Дата оновлення:** Листопад 2026  
**Місія сесії v4.0:** Успішно завершено аудит, закрито 12 багів, проведено повну модульну декомпозицію (усі файли <= 300 рядків) та переведено ядро на нативні ES-модулі.

================================================================================
1. СТАНДАРТ ТА СТАТУС АРХІТЕКТУРИ (ES MODULES + STATE STORE)
================================================================================
- Стек: HTML5 Canvas 2D, Vanilla JS (ES6+ Modules), 60 FPS.
- Запуск: VS Code Live Server (http://127.0.0.1:5500).
- Архітектурний патерн: Однонаправлений потік даних (Unidirectional Data Flow):
  1. `config.js` — незмінний баланс, версіоновані сейви (Read-only).
  2. `state.js` — ізольоване централізоване сховище поточного забігу (Single Source of Truth).
  3. Модулі систем (`player/`, `enemies/`, `weapons/`, `world/`) — чиста бізнес-логіка без глобального спагетті.
  4. Модулі рендера (`render/`) — чистий вивід на Canvas 2D, відокремлений від математики гри.
- Точка входу: `<script type="module" src="js/main.js"></script>`.

================================================================================

[x] Баг 6-7: Усунуто мутацію `CONFIG` апгрейдами та God Mode — параметри більше не «протікають» між забігами.
[x] Баг 8: Дрони більше фізично не зміщують біо-гнізда (перевірка `!enemy.alarmThresholds`).
[x] Баг 9: Податок на телепортацію розраховується від фактичної дистанції гравця до Хабу.

[x] Баг 11: Частинки влучань зброї плавно згасають через альфа-канал без застиглих артефактів.
[x] Баг 12: Полум'я турбін круїз-контролю орієнтується строго назад від кута руху спрайта.
